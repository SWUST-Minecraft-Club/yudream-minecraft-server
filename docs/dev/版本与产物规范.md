# 版本、产物与发布

## 版本唯一来源

根 `./gradle.properties` 的 `version=` 为产品唯一版本，子模块继承。采用点分 SemVer，例如 `0.3.0-beta.1`。作者字段统一为 `SWUSTMC Club`；保留原版权和第三方许可。

修复加 PATCH，功能加 MINOR，不兼容公开 API 变更加 MAJOR；0.x 的不兼容变化必须在 ChangeLog 说明。测试迭代用 `-alpha.N`、`-beta.N`、`-rc.N`，同一目标版本只增加后缀序号，转正只去掉后缀。已有发布内容和标签不覆盖、不移动。

Git 标签必须精确为 `v<version>`，例如 `v0.3.0-beta.1`。Minecraft 游戏版本独立记录，当前 26.3；Java 包/适配目录 `mc26_3` 不需改名。

## 产物和记录

Folia JAR：`<产品>-mc26.3-plugin-<version>.jar`。Fabric JAR：`<产品>-mc26.3-fabric-<version>.jar`。旧 Bukkit 桥接例外为 `yudream-minecraft-server-bukkit-<version>.jar`，保持 Java 8 字节码。

构建输出在 `./build/` 和 `./release/<产品>/`，由 Actions artifacts 或 GitHub Releases 分发，不把每次二进制构建提交到源码仓。固定跨仓编译输入放 `./libs/` 并登记 `./dependencies.lock.json`。测试夹具 `TestPlugin*` 不发布。

每次版本变化在根 `./CHANGELOG.md` 写 `## [版本] - 日期`，说明变化、兼容边界、必要验证。旧下划线 ChangeLog 保留历史，迁移来源见根 `./MIGRATION-SOURCE.md`。

## CI 与发布

Build 在 main push、PR、手动触发时检查 SemVer、ChangeLog、依赖 SHA-256，构建并运行测试，成功后上传当前产物。Java 25 构建；YudreamUI 还需 CMake、Ninja 和 FreeType，CI 自动安装，原生当前仅验证 Linux x86_64。

```bash
./gradlew build
python3 ./scripts/check-release.py --tag v0.3.0-beta.1
git tag v0.3.0-beta.1
git push origin main v0.3.0-beta.1
```

Release 在 v* 标签或手动选择已有标签时触发，校验精确版本后重新构建，成功才发布当前版本 JAR/ZIP、完整产品源码归档与 SHA256SUMS.txt；预发布后缀对应 GitHub prerelease。禁止从历史留档补缺或绕过失败测试发布。源码归档含本仓代码、原生桥与固定上游构建说明，不分发 Minecraft 客户端。
