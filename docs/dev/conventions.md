# 独立产品开发规范

## 来源与版本

本仓是对应产品的权威开发源；mcPlugin 保留更早历史和集成快照，来源见根 `./MIGRATION-SOURCE.md`。作者字段为 `SWUSTMC Club`，原版权和第三方许可必须保留。

版本唯一来源是根 `./gradle.properties`。涨号、ChangeLog、标签与产物见 [版本规范](版本与产物规范.md)。游戏当前基线 Minecraft/Folia 26.3，Java 25；Bukkit 桥接插件保持 Java 8 字节码。尚未验证其它游戏或原生平台时不宣称兼容。

## 构建和依赖

根 `./gradlew build` 独立完成构建与必要测试。不隐式读取父目录或相邻项目。跨插件依赖使用固定版本 compileOnly JAR，在根 `./dependencies.lock.json` 记录来源、版本、SHA-256；它们不嵌入产品，不把完整插件称为裁剪 API。输入说明见 [编译依赖](../DEPENDENCIES.md)。

YudreamUI 的 `./server/` 与客户端模块同仓；游戏耦合在 `./versions/mc26_3/`，协议与原生引擎不引用游戏类。其它 Mod 也保持 core/versions 已有分层。升级只适配实际采用的版本，不预建猜测兼容层。

## Folia 与数据

玩家/实体操作在对应实体调度器，世界读取在区域调度器，网络与磁盘 IO 在异步调度器；禁止 Bukkit.getScheduler。已在所属线程时可直接执行，不额外排队。跨线程共享数据使用不可变快照或同步机制。

每次执行业务重新检查权限、归属、报价和持久状态；客户端展示值不作资金依据。保留现有数据、迁移备份和交易幂等边界。测试使用隔离玩家、世界与账本。

## 文档和提交

文档用相对路径，脚本按自身位置定位；不提交运行服、缓存、本机路径、凭据或生产数据。保留用户未提交修改；提交和发布产物必须对应已提交源码。完成已授权工作后更新 ChangeLog、运行必要验证、提交 main 并推送 origin。非显然问题记录在 `./docs/exp/`。
